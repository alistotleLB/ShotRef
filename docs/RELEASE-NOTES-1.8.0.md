## ShotRef 1.8.0

A design pass over the whole screen, from a full audit of the interface. Nothing was removed; things are easier to find and the picture gets more room.

- **A calmer screen.** A chosen option now has a quiet grey outline. Orange is kept for the main button of each step, the camera and the time counter, so the next thing to press stands out.
- **A bigger picture.** In the Frame and Export steps the left panel folds to a thin strip. Click the strip, or go back to Build, to open it again.
- **One home for each control.** The camera panel has three tabs: Shot, Move and Lens. The aspect ratio and the guides sit above the picture, and Set start and Set end appear once.
- **A better first minute.** Starter sets show a picture of each set and open on a clear view of the scene. An empty stage tells you how to begin, and Quick start is seven short steps.
- **Clearer messages.** They appear at the top of the view: a green tick when something finished, a red edge when something needs you. Tooltips appear at once, and buttons use drawn symbols.
- **A clear finish.** Exporting a video ends on a "Video saved" window with the file name and where it was saved.
- **Windows app.** One File menu, at the top of the window, with Recent projects and Export. ShotRef remembers the size and place of its window, and says "on this computer" where the web version says "in this browser".

If you have 1.3.0 or newer installed, ShotRef offers this update by itself (or use **Help, Check for updates…**). On 1.2.0 or older, install this version by hand once.
