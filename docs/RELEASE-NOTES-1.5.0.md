## ShotRef 1.5.0

- **What's new after an update.** The first time the Windows app starts on a new version, it lists everything that changed since the version you had, newest first. **Help, What's new** shows it again.
- **Messages look like ShotRef, with no alert sound.** Update messages, About and file errors in the Windows app now use ShotRef's own dark box with the orange viewfinder corners, instead of the plain Windows box and its "ding".
- **About ShotRef** shows the version and the slogan.

If you have 1.3.0 or newer installed, ShotRef offers this update by itself (or use **Help, Check for updates…**). On 1.2.0 or older, install this version by hand once.

### Download

| You want | File |
|---|---|
| Windows app with installer (updates itself) | `ShotRef-Setup-1.5.0.exe` |
| Windows app, no install | `ShotRef-1.5.0-portable.exe` |
| Any computer with Chrome or Edge | `ShotRef.html` |

The Windows builds are not code-signed yet, so SmartScreen may say "Windows protected your PC". Click **More info**, then **Run anyway**.

`latest.yml` and the `.blockmap` file are what the in-app updater reads. You can ignore them.
