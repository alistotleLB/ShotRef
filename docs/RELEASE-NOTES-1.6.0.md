## ShotRef 1.6.0

- **A calmer, clearer screen.** Each section of the settings panel sits on its own card with a clear heading, the colours have more depth, and a chosen option always looks the same: an orange outline. The settings panel is a little wider.
- **Less on screen, nothing lost.** Panels show what you use most. The sun panel shows only the sun, Simple mode shows three sun controls, and rarely used sections (Animation, Attach, Save as set, Mount) start folded unless they're in use. Every control is still there.
- **Picture tiles.** Scene presets, cloud cover and "Light the shot from" are pictures, so you can see the look before you pick it.
- **Shorter labels, one name for each thing.** For example "Aim camera at this", "Mount camera on this", "Clear move" and "Export video (MP4)".
- **Export panel in workflow order.** A one-line summary of the format (size, aspect, style) with **Change**, then Export video, Frame pack and the prompt.
- **Skies with clouds.** Pick the cover (Clear to Overcast), the look and how fast they drift, or shuffle them. Clouds soften the sun's light and shadows, and the prompt names the sky.
- **Drag and drop.** Drag people and props from the Add panel straight onto any view.

If you have 1.3.0 or newer installed, ShotRef offers this update by itself (or use **Help, Check for updates…**). On 1.2.0 or older, install this version by hand once.
