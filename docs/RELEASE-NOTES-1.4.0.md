## ShotRef 1.4.0

- **A quick tour of the screen.** The first time you open ShotRef, it asks **Take a look round the set?** The quick tour has 10 stops: orange viewfinder corners frame each part of the screen (the three steps, the Add tab, the picture, the View buttons, the right-hand panel, the timeline, File and the gear menu), with one or two plain sentences on each. It changes nothing in your scene. Use **Next**, **Back**, or **End tour** (or Esc) at any time.
- **Take it again whenever you like.** The tour is in the **Help** menu: under **Help** in the gear menu in the browser, and in the Windows app's **Help** menu. It's also at the top of the **Quick start** page.
- Updated user guide.

If you have 1.3.0 or newer installed, ShotRef offers this update by itself (or use **Help, Check for updates…**). On 1.2.0 or older, install this version by hand once.
