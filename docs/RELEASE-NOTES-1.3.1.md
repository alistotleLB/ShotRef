## ShotRef 1.3.1

- **View buttons moved.** Editor, Top and Camera (and the split-view button) now sit in a **View** group in the row under the picture, between your Shots and the Contact sheet button. The top bar is cleaner, and the step bar stays centred.
- Updated Quick start text, user guide and screenshots to match.

If you have 1.3.0 or newer installed, ShotRef offers this update by itself (or use **Help, Check for updates…**). On 1.2.0 or older, install this version by hand once.

### Download

| You want | File |
|---|---|
| Windows app with installer (updates itself) | `ShotRef-Setup-1.3.1.exe` |
| Windows app, no install | `ShotRef-1.3.1-portable.exe` |
| Any computer with Chrome or Edge | `ShotRef.html` |

The Windows builds are not code-signed yet, so SmartScreen may say "Windows protected your PC". Click **More info**, then **Run anyway**.

`latest.yml` and the `.blockmap` file are what the in-app updater reads. You can ignore them.
